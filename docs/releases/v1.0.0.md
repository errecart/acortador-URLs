# v1.0.0

Initial release of the zero-dependency URL shortener.

## Highlights

- Browser UI, JSON HTTP API, and command-line client.
- Persistent short links with visit statistics and an append-only access log.
- Input validation, request-body and URL length limits, security headers, and configurable HTTP timeouts.
- Atomic, serialized JSON-store writes with deferred visit-count flushing.
- Restricted-filesystem startup option using the Node.js permission model.
- Automated test suite for Node.js 22 and 24.

## Requirements

- Node.js 22 or newer.

## Getting started

Copy `.env.example` to `.env`, then run `npm run dev` and open <http://localhost:3000/>.
